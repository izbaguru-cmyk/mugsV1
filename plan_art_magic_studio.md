# План создания сайта Art Magic Studio (Django + HTMX + Tailwind + DaisyUI)

## 1. Анализ и структура
- Название: Art Magic Studio
- Сфера: подарочные кружки с надписями/рисунками, имена на разных языках (татарские, и т.д.), категории (день рождения, женщины, бабушка)
- Стек: Django 4.2+, Django Templates, HTMX (AJAX без JS), Tailwind CSS, DaisyUI (компоненты)

## 2. Архитектура проекта
- Приложения Django:
  - `shop` — товары (кружки), категории, заказы
  - `catalog` — фильтры, имена, языки/народности
  - `users` — авторизация, профили
  - `cart` — корзина (сессии или БД)
- БД: PostgreSQL или SQLite (для старта)

## 3. Модели (пример)
- `Category` — День рождения, Для женщин, Для бабушки, Для татарской культуры и т.д.
- `Name` — Имя (текст, язык/народность, транслитерация)
- `Product` — Кружка (название, описание, цена, изображение, категория, связанные имена)
- `Order` / `OrderItem`

## 4. Фронтенд (HTMX + Tailwind + DaisyUI)
- Базовый шаблон с DaisyUI темой (light/dark)
- HTMX для:
  - Фильтрация товаров (по категории, имени, языку) без перезагрузки страницы
  - Добавление в корзину
  - Быстрый предпросмотр товара (modal)
  - Пагинация
- Tailwind для сетки, типографики, адаптивности
- DaisyUI: navbar, cards, buttons, dropdowns, modal, badges

## 5. Ключевые страницы
- Главная: баннер «Art Magic Studio», подборки (татарские имена, для дня рождения, для бабушки), популярные
- Каталог: фильтры слева (категории, языки/народности, случаи), сетка товаров HTMX
- Карточка товара: фото, варианты надписи/имени, цена, «В корзину» (HTMX)
- Корзина: мини-корзина в шапке, страница корзины с изменением количества (HTMX)
- Оформление заказа: форма + HTMX валидация
- Страница «Имена»: каталог имён на разных языках с привязкой к кружкам

## 6. Особенности контента
- Разделы по народностям/языкам: татарские имена, русские, арабские и т.д.
- Случаи: ДР, женщинам, бабушке, маме, ребёнку
- Возможность персонализации: выбор имени из списка или ввод своего

## 7. Этапы разработки (поэтапно)
1. Инициализация проекта Django, настройка окружения
2. Модели + админка + загрузка тестовых данных (кружки, имена)
3. Базовые шаблоны (DaisyUI + Tailwind)
4. Главная и каталог с HTMX-фильтрацией
5. Карточка товара и корзина (HTMX)
6. Оформление заказа и оплата (можно интегрировать платежный шлюз позже)
7. Страница имён и персонализация
8. Адаптив, SEO, оптимизация изображений
9. Деплой (PythonAnywhere / Render / VPS)

## 8. Технологические решения
- HTMX: подключить через CDN или npm; использовать `hx-get`, `hx-target`, `hx-swap`
- Tailwind: CDN для прототипа или сборка через PostCSS/webpack
- DaisyUI: CDN или npm + конфиг tailwind
- Изображения: Pillow для миниатюр, хранение в media/

## 9. Что сохранить в проект позже
- ТЗ с подробными описаниями страниц (текст)
- Макеты/вайрфреймы в Figma или просто описания
